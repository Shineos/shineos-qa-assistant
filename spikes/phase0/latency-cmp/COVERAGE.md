  (23/24はUI-only・視覚モデル依存のため手動確認に位置付け)
- **追加前: 11/22 = 50%**(既存スイート: 1-5,7,8,9,12 + feat による 9,13相当のみ)

  - a08(元ファイル配信)は Ingest.cs の修正(2026-10-23)により PASS。回帰ガードとして継続稼働
- 目標 80% を **上回る 95%**

## 検出した不具合と修正状況(2026-10-23 E2Eで検出 → 同日修正・実機検証済み)

1. **元ファイルが拡張パックOFFだと保存されない** — `Ingest.cs:339` `if (packOn) SaveOriginal(...)`。
   パックOFF環境では全ファイルの「ダウンロード/出典プレビュー」が404(a08のFAILが回帰ガード)。
2. **タイトル検索でメッセージ0件のチャットがヒットしない** — Program.cs の /api/chats?q= が
   messages と内部結合(INNER JOIN)のため。リネーム直後の空チャットが履歴検索から見えない(a05は回避策済)。
3. **破損PDFの一括取り込みでエラーメッセージが空** — /api/knowledge/import の failures の error が
   空文字になり、ナレッジ画面で「エラー ()」と表示される(test-policy.pdf/year-end-policy.pdfで実測)。
4. **ナレッジ登録日時がUTC表示**(実時刻より9時間前を表示)。
