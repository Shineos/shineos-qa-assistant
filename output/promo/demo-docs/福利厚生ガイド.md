# 【福利厚生】福利厚生ガイド

## フィットネス（ジム）利用補助

- 全国の提携フィットネスクラブの利用料を補助します
- 補助額: 月額利用料の 50%（上限 5,000円/月）
- 申請方法: 福利厚生ポータルから「スポーツクラブ利用補助」を選択し、
  会員証と領収書をアップロードしてください
- 申請は四半期ごとの締めで精算されます

## リフレッシュ休暇

- 勤続5年、10年、15年の節目に3日間のリフレッシュ休暇を付与
- 取得期限は付与年度内（繰り越し不可）
- 休暇取得時は旅行費用の補助（10万円上限）を申請できます

## 社宅・家賃補助

- 自宅からオフィスまでの通勤が2時間を超える社員を対象に、家賃補助（月30,000円上限）を支給します
- 入居申請は総務部までご相談ください
