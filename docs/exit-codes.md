# 終了コード一覧（Exit Codes）

本ドキュメントは、社内知恵袋（ShineosQA）のインストーラおよび同梱スクリプトが返す終了コードをまとめたものです。

- **対象**: `ShineosQA-Setup-<version>.exe`（Inno Setup 6.7.3 製）および `{app}\scripts` 配下のスクリプト
- **方針**: インストーラ本体の終了コードは **Inno Setup の標準コードに一本化**しています。独自の終了コードは実装していません（重複実装の防止。Microsoft Store 申請時の「EXE リターン コード値」もこの表に基づきます）

## 1. インストーラ（ShineosQA-Setup-*.exe）の終了コード

Inno Setup の標準終了コードをそのまま返します。公式ドキュメント:
<https://jrsoftware.org/ishelp/topic_setupexitcodes.htm>

| コード | 意味（Inno Setup 公式） |
|---|---|
| **0** | 正常に完了。`/HELP` または `/?` パラメータ使用時もこれを返す |
| **1** | セットアップの初期化に失敗（ダウンロード破損、別インスタンスの実行、セキュリティポリシーによるブロックなど） |
| **2** | **実インストール開始前**にユーザーが Cancel を押した、または冒頭メッセージで「いいえ」を選んだ |
| **3** | インストール段階の移行準備中に致命的エラー（非常に稀。メモリ不足など） |
| **4** | **実インストール処理中**に致命的エラー |
| **5** | **実インストール処理中**にユーザーが Cancel を押した、または Abort-Retry-Ignore で Abort を選んだ |
| **6** | デバッガ（Inno Setup コンパイラ IDE）により強制終了された |
| **7** | 「インストールの準備中」段階で続行不可能と判断された |
| **8** | 「インストールの準備中」段階で、再起動しないと続行できないと判断された |

注意事項（公式ドキュメントより）:

- コード 1, 3, 4, 7, 8 の前には通常、問題を説明するエラーメッセージが表示される
- **非ゼロの終了コードはすべて「セットアップが完了しなかった」ことを意味する**
- 将来の Inno Setup は追加のコードを返す可能性があるため、終了コードをチェックする側は未知のコードも gracefully 扱うこと

## 2. シナリオ別の対応表（Microsoft Store 申請・無人展開用）

各シナリオが**重複しない一意の終了コード**を持つ（v1.0.76）。0〜8 は Inno Setup 標準、11 以上は本インストーラの独自コード（カスタム終了コード機構により返却）です。

| シナリオ | 終了コード | 補足 |
|---|---|---|
| インストールがユーザーによりキャンセルされました | **2** | 本インストーラの長時間処理（モデルのダウンロード等）はウィザード段階で実行されるため、キャンセルは「実インストール開始前」に該当する（Inno 標準） |
| アプリケーションは既に存在します | **11** | **同一バージョンが完了済み**の環境に `/VERYSILENT` で再実行した場合に返す（対話実行時はモデル再選択・修復のため通常どおり実行され、アップグレードは 0 で完了） |
| インストールは既に処理中です | **1** | 二重起動は初期化時の多重起動チェックで拒否される（Inno 標準） |
| ディスク領域がいっぱいです | **12** | インストール前に空き容量をチェックし、15GB 未満の場合に返す（v1.0.76 で追加。システムドライブと Program Files 配下のドライブが対象） |
| 再起動が必要 | **8** | 本インストーラは再起動を要求しない設計のため通常返らないが、意味上の対応として Inno の「再起動が必要」コードを指定する（**0 と指定すると成功が再起動要求と誤解されるため不可**） |
| ネットワークエラー | **13** | Python ランタイム・Ollama 本体・AIモデルのダウンロードが失敗した場合に返す（v1.0.76 で追加。`--retry` 付きの自動再試行後の失敗） |
| インストール中にパッケージが拒否されました | **14** | セキュリティポリシー（AppLocker 等）はプロセス起動自体をブロックするため、本 EXE の終了コードとしては観測されない（クライアント側の起動エラーとして検出される）。参考値として割り当て |
| インストールが正常に完了しました | **0** | 成功 |

### 無人インストール（サイレント展開）時の挙動

```
ShineosQA-Setup-1.0.75.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

- AI モデルは検出 RAM により自動選択される（8GB未満=1.5b / 8〜16GB=3b / 16GB以上=7b）
- ナレッジは同梱サンプルのみ登録される
- **同一バージョンが完了済みの場合は再インストールを行わず 11 で終了する**（ステップの再実行をしないため即座に返る。失敗途中で完了マーカーがない環境では従来どおり再開する）
- ステップ失敗時はメッセージが抑制され、セットアップは完了しないまま終了する（終了コードは非ゼロ）。失敗ステップの詳細は `{app}\install.log` と `{tmp}\step_error.txt` に記録される
- 完了の成否は終了コードに加え、`{app}\install.log` の最終行（`===== ALL STEPS COMPLETED =====`）でも確認できる

## 3. 内部スクリプトの終了コード（install.log 調査用）

セットアップ EXE は内部で PowerShell / Python スクリプトを順次実行します。これらの終了コードは **`{app}\install.log` 上の `STEP FAILED: <名前> (exit <コード>)` として記録され**、失敗原因の切り分けに使用します。※ これらはセットアップ EXE 自身の終了コードではありません。

| スクリプト | 終了コード |
|---|---|
| `run_all.ps1`（全体オーケストレーター） | 0 = 全ステップ成功 / 非0 = 失敗ステップの終了コード（`13` = ネットワーク起因のダウンロード失敗、`90` = アプリフォルダへの書き込み不可） |
| `preflight.ps1`（環境チェック） | 0 = チェックOK / 1 = 問題あり（※ ディスク空き容量は終了コードでなく ini の `disk_ok` で報告） |
| `setup_python.ps1` | 0 = 成功 / 13 = ダウンロード失敗 / 非0 = 失敗 |
| `setup_ollama.ps1` | 0 = 成功 / 13 = ダウンロード失敗 / 非0 = 失敗 |
| `setup_openwebui.ps1`（モデルDL / 本体導入） | 0 = 成功 / 13 = モデルのダウンロード失敗 / 非0 = 失敗 |
| `register_service.ps1` | 0 = 成功 / 非0 = 失敗 |
| `configure_model.ps1` | 0 = 成功 / 非0 = 失敗 |
| `setup_knowledge.ps1` | 0 = 成功（対象なし含む） / 非0 = 失敗 |
| `wait_ready.ps1` | 0 = 起動完了 / 1 = タイムアウト |
| `warmup_model.ps1` | 0 = 成功（スキップ含む） / 1 = 失敗 |
| `smoke_test.py`（導入検証） | 0 = 全項目合格 / 1 = 不合格 |
| `patch_openwebui_*.py`（パッチ適用） | 0 = 適用済み（または適用完了） / 1 = 失敗 |
| `attach_knowledge_to_models.py` | 0 = 成功（紐付け済み含む） / 1 = 失敗 |
| `preserve_uploads.py`（アップグレード時の退避） | 0 = 成功（退避対象なし含む） / 1 = 失敗（処理続行可能・警告のみ） |
| `repair_middleware.py`（修復） | 0 = 成功 / 1 = 失敗 |

補足:

- `run_all.ps1` は 4 時間経過しても完了しない場合、内部的にタイムアウト扱い（コード 124）として処理します（進捗表示用の値であり、セットアップ EXE の終了コードではありません）
- 各ステップの成否は `{app}\install.log` に `STEP START` / `STEP OK` / `STEP FAILED` として記録されます

## 4. ログの場所

| ログ | 場所 |
|---|---|
| セットアップの内部ログ | `C:\Program Files\ShineosQA\install.log`（既定） |
| Inno Setup 自体のログ | `/LOG="<パス>"` パラメータで指定した先 |
| 実行時ログ | `C:\Program Files\ShineosQA\logs\`、`%APPDATA%\ShineosQA\app.log` |
