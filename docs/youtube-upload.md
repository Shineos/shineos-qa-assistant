## 3. 説明文

上限5,000文字（本稿 1,388文字）。以下をそのまま貼り付け。

```
社内の規定やマニュアルを探す時間を、減らしませんか。

「社内知恵袋」は、社内の規定・業務マニュアルをナレッジとして登録し、質問するだけで出典付きの回答を返す Windows アプリです。AIはお使いのパソコンの中で動作するため、社内資料も質問内容も外部に送信されません。

■ 動画で紹介している内容
0:00 質問から出典付きの回答まで
0:15 出典から原文の該当箇所を確認
0:27 ナレッジ登録と、追加した資料への質問
0:51 AIモデルの切り替えと設定

■ 主な機能
・社内Q&A：登録した社内文書から、根拠（文書名・該当箇所）付きで回答します
・ナレッジ登録：PDF・Word・Markdown・テキストをドラッグ＆ドロップで追加。追加した資料はすぐに検索対象になります
・ハイブリッド検索：キーワード一致（BM25）と意味での一致（ベクトル検索）を併用し、型番や規程番号・固有名詞も正確にヒットします
・3階級の回答モデル：⚡クイック（1.7B）／🎯標準（4B）／🏆高品質（30B）を画面から即切り替え
・推測しない回答：ナレッジに記載がない場合は推測せず「該当する記載がありません」と回答します
・他アプリ優先モード（既定ON）：AI処理を低優先度で実行し、同時に使っているアプリの操作を優先します
・閉じたら完全停止：アプリを閉じるとAIエンジンも停止し、メモリを解放します（常駐しません）

■ 動作環境
・Windows 10 / 11（64bit）・GPU不要（CPUのみで動作）
・メモリ 8GB 以上（16GB 以上なら🏆高品質30Bも選択可）
・フル版インストーラ：初期インストール約3GB（⚡クイック同梱・オフラインでインストール可能）
・Microsoft Store版：インストール約0.2GB＋初回起動時にモデル約2.3GBを取得

■ プライバシー
テレメトリ・利用統計・クラッシュレポートはありません。既定の状態では外部への通信は発生せず、社内文書・チャット履歴・検索データはすべてお使いのPC内にのみ保存されます。
（任意機能のWeb検索をONにした場合のみ、入力した質問が外部の検索サービスへ送信されます。既定はOFFです）

■ ダウンロード

※ 直接ダウンロード版は現在テスト証明書での署名のため、SmartScreenが「認識されないアプリ」と表示することがあります。その場合は「詳細情報」→「実行」を選択してください。
※ Microsoft Store での配布も準備中です。

お問い合わせ: https://shineos.com/contact/

#社内Q&A #ローカルLLM #社内知恵袋 #オフラインAI #RAG #ナレッジ管理 #Windowsアプリ
```

## 7. 音声についての注意

この動画は**音声トラックを持たない**（ナレーション・BGMなしの設計）。無音で再生されるため、
視聴者が「音が出ない」と誤解しないよう、次のいずれかを実施する。

1. **YouTube Studio の編集機能で音楽を追加**（Studio「エディタ」→「音楽」からAudio Libraryの曲を追加）
2. 無音のまま公開し、説明文の冒頭かピン留めコメントに「音声なしの解説動画」と明記
3. 外部でBGMを付けて再アップロード（動画の再生成が必要。[9章](#9-動画を作り直したときの手順)参照）

## 9. 動画を作り直したときの手順

動画はローカルのビルドキットで生成している（リポジトリ管理外の `output/promo/` 配下）。

| ファイル | 役割 |
|---|---|
| `output/promo/promo-config.json` | エンドカードのURL（QRコードも自動生成される） |
| `output/promo/build-promo.js` | 全ショットの編集・書き出し・サムネイル生成（`node build-promo.js`） |
| `output/promo/cards/title.html` | 冒頭カード＝サムネイルの元デザイン（1920x1080で撮影） |
| `output/promo/cards/end.html` | エンドカードの下地（QRとURLはビルド時に合成） |
| `output/promo/recordings/` | 実機操作の録画素材 |

再生成後は `assets/videos/` の動画・サムネイルを差し替え、**チャプター時刻を再計算**する
（`build-promo.js` の `shots` 配列の各ショット長 ÷ 1.2 の累積）。詳細は `output/promo/README.md` を参照。
