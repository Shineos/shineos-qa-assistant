# v2 エラーコード・終了コード・サイレントインストール仕様（Microsoft Store対応）

- 最終更新: 2026-09-14（実装に合わせて全面改訂）
- 対象: v2アーキテクチャ（[architecture-v2.md](architecture-v2.md)）のインストーラとバックエンド
- 継承: v1の [exit-codes.md](exit-codes.md) の方針（Inno標準コード＋独自コードは一意のみ）を引き継ぎ、
  **製品内の全終了コードが単一の名前空間で重複しない**よう番号帯を分離した

---

## 1. 設計原則

1. **シナリオ別に一意な終了コード**: Microsoft Store のインストール分析および無人展開が失敗を分類できる。1つのコードが複数シナリオを兼ねない
2. **単一名前空間・番号帯の分離**: プロセスが異なっても同じ数値が別の意味を持つことを禁止する
   - `0` = 成功（全プロセス共通）
   - `1–8` = Inno Setup 標準（セットアップEXEのみ）
   - `11–14` = インストーラ独自コード（セットアップEXEのみ・v1.0.76と同じ意味を維持）
   - `20–30` = バックエンドプロセス（ShineosQA.Backend.exe）
   - 文字列コード（`SHINE_E_*`）= ランタイムAPI（数値と名前空間が異なるため衝突しない）
3. **成功=0・再起動要求なし**: すべての経路で再起動を要求しない（Inno標準8は返さない設計）
4. **サイレントファースト**: 対話UIなしで全機能が使える（§5）

## 2. インストーラ（ShineosQA-Setup-2.x.exe）の終了コード

0〜8 は Inno Setup 標準（v1と同一）。11 以上が本製品の独自コード（カスタム終了コード機構
`DeinitializeSetup` + `ExitProcess` により返却。**v1の11〜14の意味は変更しない**）:

| コード | シナリオ | v2での発生条件 |
|---|---|---|
| **0** | 成功 | インストール完了 |
| 1 / 2 / 3 / 4 / 5 | Inno標準（初期化失敗／開始前キャンセル／準備中エラー／処理中エラー／処理中キャンセル） | Inno機構による |
| **11** | 同一バージョン完了済み | `/VERYSILENT` で完了マーカー（`install.completed`）がある同一バージョン環境に再実行した場合。再インストールせず即終了（対話実行時は修復のため通常どおり実行） |
| **12** | ディスク空き容量不足 | インストール先ドライブの空き容量が 4GB 未満（同梱物: バックエンド約130MB＋エンジン＋モデル約2GB） |
| 13 / 14 | （予約・v2では返さない） | v1互換の意味は「13=ダウンロード失敗」「14=ポリシー拒否」。v2はインストール中にダウンロードしないため返却しない。将来のビルドバリアント（モデル別exe）で使用する可能性があるため番号は欠番として維持する |

未使用の番号（15, 16, 20以外の17–19など）は将来の失敗モード追加用の予備。

## 3. バックエンドプロセス（ShineosQA.Backend.exe）の終了コード

v2 は Windowsサービスではなく、アプリ起動時に `launch.vbs` からオンデマンド起動される
通常プロセス。終了コードは障害調査（`{app}\data\logs\backend-*.log` との突合）に使う:

| コード | シナリオ | 回復手段 |
|---|---|---|
| **0** | 正常停止（アプリ終了・シャットダウン） | — |
| **20** | `config.json` の読込・解析に失敗 | config.json 再生成（再インストールで修復） |
| **21** | ポートバインド失敗（既定8300が使用中） | 起動中の別インスタンス終了、または config.json の port 変更 |
| **22** | `knowledge.db`（SQLite）の初期化・オープン失敗 | 該当ログの確認。データ破損時は当該dbのバックアップ・再作成 |
| **30** | 想定外の致命的例外 | ログのスタックトレースを確認 |

子プロセス（llama-server）の異常終了は**バックエンドを落とさない**: スーパーバイザが検出して
再起動（embed/rankは自己修復、リランカは復旧不能時デグレード）。

## 4. ランタイムAPIのエラー（文字列コード・実装済み）

チャットAPIは SSE ストリーム中に `error` イベントで返す（HTTPステータスは接続成功後のため200）:

```json
{ "event": "error", "data": { "code": "SHINE_E_MODEL_NOT_FOUND", "message": "AIモデルが未インストールです。…", "detail": "…" } }
```

実装済みコード: `SHINE_E_MODEL_NOT_FOUND`（モデル未DL）、`SHINE_E_ENGINE_DOWN`（エンジン起動失敗）、
`SHINE_E_INTERNAL`（内部エラー）。取り込み系は `SHINE_E_DOC_PARSE_FAILED`（未対応形式など）。
文字列コードは数値終了コードと名前空間が異なるため重複しない。
NO-HIT（ナレッジ外質問）は**エラーではなく**正常応答「該当する記載がありません」。

## 5. サイレントインストール・アンインストール仕様

### 5.1 インストール（無人・実機検証済み）

```
ShineosQA-Setup-2.0.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART [/LOG="<path>"]
```

- 管理者権限不要（`PrivilegesRequired=lowest`・`%LOCALAPPDATA%\Programs\ShineosQA` にユーザー単位で配置）
- インストール中のダウンロードなし（エンジン・初期モデル1.7B・埋め込み・リランカを同梱）→ オフラインで完結
- 完了判定: 終了コード 0 ＋ `{app}\install.completed` マーカー
- 同一バージョン再実行時は 11 で即終了（失敗途中の再実行はマーカーがないため再開できる）

### 5.2 アンインストール（無人）

```
unins000.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

- アプリ本体（exe・エンジン・同梱モデル）を完全削除。実行中のプロセスは自動停止
- **ナレッジ（`{app}\data`）の扱い**: 対話時は「データも削除するか」を確認。サイレント時は**残す**
  （残ったデータは再インストール後も利用可。アプリ本体は完全削除されるためStoreのクリーンアンインストール要件と整合）

### 5.3 アップグレード

同一 AppId の上位バージョンをそのままインストール（設定・ナレッジ・DL済みモデルは保持）。

## 6. Microsoft Store 申請対応チェックリスト

方針: **Inno Setup 製 EXE を Store の EXE インストーラ提出対応で申請する**（MSIX化不要）。

| 要件 | v2での対応 | 状態 |
|---|---|---|
| インストーラ形式 `.exe` | Inno Setup EXE | ✓ |
| **完全オフラインインストーラ** | エンジン・モデルを同梱（ダウンロードなし） | ✓ |
| サイレントインストール | `/VERYSILENT`（§5.1・実機検証済み） | ✓ |
| 一意なリターンコード | §2の表（0/1-8/11/12） | ✓ 実装済 |
| 再起動を要求しない | 全経路で要求なし | ✓ |
| クリーンアンインストール | §5.2（本体完全削除・データは明示的に選択） | ✓ |
| 管理者権限不要 | ユーザー単位インストール | ✓ |
| OSS・モデルライセンス | [vendor/THIRD-PARTY-NOTICES.txt](../vendor/THIRD-PARTY-NOTICES.txt) ＋ ライセンス全文を `{app}\licenses` に同梱 | ✓ 今回整備 |
| **全PEファイルのコード署名（信頼CA）** | 現在テスト証明書。SignPath Foundation 承認後に正式署名へ | ⚠️ 残課題 |
| プライバシーポリシーの公開URL | PRIVACY.md を shineos.com 上のURLとして提出用に公開する必要 | ⚠️ 残課題 |
| Partner Center 登録・審査情報（スクリーンショット・年齢区分等） | 申請事務手続き | ⚠️ 残課題 |

## 7. ログ

| ログ | 場所 | 内容 |
|---|---|---|
| バックエンド | `{app}\data\logs\backend-YYYYMMDD.log` | 起動・終了（終了コード要因）・エンジン起動/停止・APIエラー |
| エンジン | `{app}\data\logs\engine-<llm\|embed\|rank>.log` | llama-server の stderr（起動フラグ付き） |
| インストーラ | `/LOG=` 指定時、または `%TEMP%` | Inno 標準ログ |
