# 社内知恵袋 — ユーザーマニュアル

> 社内規定・業務マニュアルをナレッジ化して、社内Q&Aをパソコンの中だけで安全に実現するツールです。
> インストールした後は、インターネットに接続しなくても使えます。

## 1. 必要なもの

| 項目 | 条件 |
|------|------|
| OS | Windows 10 / 11（64bit） |
| メモリ | 8GB 以上（16GB 以上推奨） |
| 空き容量 | 15GB 以上 |
| インストール時 | インターネット接続が必要（Ollama本体1.5GB＋AIモデル3.4GBなど**合計約6GB**をダウンロードします。所要時間は回線によりますが、およそ30〜90分です） |

## 2. インストール方法

1. [GitHub Releases](https://github.com/Shineos/shineos-qa-assistant/releases) ページから `ShineosQA-Setup-<version>.exe` をダウンロード
2. ファイルをダブルクリック
   - SmartScreenに「認識されないアプリ」と表示された場合: 「**詳細情報**」→「**実行**」をクリック
   - それでも起動できない場合: ファイルを右クリック → プロパティ → 全般タブ →「**ブロックの解除**」にチェック → OK → 再度ダブルクリック
3. 管理者権限の確認が出たら「はい」をクリック
4. AIモデルを選択:
   - **qwen2.5:3b（推奨）** — 高速・確実（約1.9GB・応答約1秒・8GBメモリ機でも快適）
   - **qwen2.5:7b（高品質）** — 日本語品質が高い（約4.7GB・16GB以上のメモリ推奨）
   - **qwen2.5:1.5b（軽量）** — 8GB機に最適・最速（約1GB・応答1秒未満）
5. インストールが完了するまで待つ（進捗画面が表示されます）
6. 完了後、デスクトップの **「社内知恵袋」** をダブルクリック

**これで完了です。アカウント登録もログインも不要で、そのままチャットを始められます。**
チャット画面では「社内知恵袋」というモデルが自動選択されています（ツール無効化・思考モード無効化済みの最適化モデル。回答が必ず表示されるように調整されています）。
アプリ画面を閉じるとサービスも停止し、次に開いたときは自動で再起動します。ブラウザで使いたい場合は **http://localhost:8080** を開いてください。

デスクトップに「社内知恵袋」のショートカット（ブラウザで開く）と「ShineosQA-はじめに.txt」が作成されます。

## 3. 使い方

### チャット
- デスクトップの「社内知恵袋」を開くとアプリ画面が表示されます（URL入力は不要）
- 画面下部の入力欄に日本語で質問を入力し、送信
- **用途別プリセット**: 画面右上のモデル選択で「**社内知恵袋**」（汎用）「**経費精算ガイド**」「**ITヘルプデスク**」を切り替えられます（質問の種類に合わせて選択するだけ）
- **アプリを閉じるとサービスも停止します**（次に開いたときは自動で再起動）

### 社内Q&A（ナレッジ検索）
- インストール時に、インストール画面で指定したフォルダ（または同梱サンプル `QA_list.md`）の社内文書（PDF・Markdown）が**自動でナレッジ登録**されます
- 資料の追加は、**アプリ画面（Open WebUI）のナレッジメニューからいつでも可能**です（ファイルをドラッグ＆ドロップするだけ。追加した資料は自動で検索対象になります）
- **登録できる形式**: PDF・Word（DOCX）・**PowerPoint（PPTX）**・Markdown（MD）・TXT などテキストを含むファイル
- **登録できない形式**: 画像ファイル（PNG・JPEG等）や、テキストが含まれないファイル。追加すると「画像ファイルはナレッジに登録できません…」というメッセージが表示されます
- チャットで質問すると、**ナレッジの該当箇所を引用した回答**が返ります（文書名・該当箇所つき）
- ナレッジに回答がない場合は、推測せず「該当する記載がありません」と回答します（ハルシネーション抑制）
- ファイル名や文書の先頭に **【人事規程】【経費精算】** などのタグを付けると検索精度が上がります

※ 文書はすべてパソコンの中だけで処理され、外部に送信されません。

### 文書を削除・差し替えたとき
- ナレッジ画面からファイルを削除すると、以後その文書は参照されません
- まれに削除済み文書の内容が答えられ続けることがあります（索引の残骸）。その場合は管理者権限で次の掃除ツールを実行してください（削除した文書に含まれる語を `--needles` に指定します）:
  ```
  sc stop ShineosQA
  "C:\Program Files\ShineosQA\venv\Scripts\python.exe" "C:\Program Files\ShineosQA\scripts\purge_orphan_vectors.py" --needles "消した文書の固有語"
  sc start ShineosQA
  ```

### Web検索（既定 OFF・オプション）
- Web 検索は**最初は OFF** になっています（社内情報の外部送信を防ぐため）
- チャット入力欄の **Web検索ボタン** をONにすると、最新のインターネット情報を参照して回答します（DuckDuckGo・APIキー不要）
- **注意**: ON にすると、**入力した質問が外部の検索サービスに送信されます**。社内情報を質問するときは OFF のままにしてください
- 検索サービスの利用制限により、一時的に検索結果が空になることがあります。しばらく待ってから再度お試しください
- **完全オフラインで使いたい場合**: Web検索ボタンをOFFのままにしてください。これだけで、一切インターネットに接続しません

### 資料作成（/doc コマンド）
- チャットで「/doc 〜について」のように送ると、**ナレッジ（社内文書）から材料を集めて PDF を自動生成**します
  - 例: `/doc 経費精算の手順について`
- 作成の流れ（すべて自動・約1〜2分）: 目次生成 → 社内文書を検索して各セクションを執筆 → PDF 生成 → ダウンロードリンクを回答
- **社内文書に材料がないセクションは「社内資料に該当記載がありません」と明記されます**（推測で文章を埋めません）
- 生成された PDF は PC 内に保存され（7日後に自動削除）、リンクやソース欄からオフラインで開けます（外部送信はありません）
- 資料作成の材料は**ナレッジ（社内文書）のみ**です。Web検索の結果は材料に含まれません

### PCの再起動後
自動的にサービスが起動するので、デスクトップの「社内知恵袋」を開くだけです。

## 4. アンインストール

1. 設定アプリ → アプリ → インストールされているアプリ → 「社内知恵袋」→ アンインストール
2. サービス・ファイル・データが自動的に削除されます
3. 確認ダイアログ「OllamaとAIモデルも削除しますか？」で選択:
   - **「はい」**: Ollama本体・ダウンロード済みAIモデル（約3.2GB）もすべて削除します（再インストール時は再ダウンロードが必要）
   - **「いいえ」**: 社内知恵袋 だけを削除し、Ollama は残します

※ 「いいえ」で残した場合は、`ollama rm qwen2.5:3b qwen2.5:1.5b bge-m3` でモデルのみ削除するか、設定アプリから Ollama をアンインストールしてください。

## 5. 困ったときは

| 症状 | 対処 |
|------|------|
| ブラウザで開けない | 数分待ってから再読み込み。それでもダメなら PC を再起動して http://localhost:8080 を開く |
| ログイン画面が表示された | ブラウザの履歴・Cookieを削除して再読み込み（まれに表示されることがあります） |
| 回答が遅い | ブラウザの不要なタブを閉じると改善します。軽量モデル（qwen2.5:1.5b）に切り替えるには、インストーラを再実行して「軽量」を選択してください |
| エラーが発生した | `C:\Program Files\ShineosQA\logs` のログを確認。またはインストーラを再実行（途中から再開されます） |
| サービスの状態を確認したい | 管理者PowerShellで `sc query ShineosQA` |

### よくある質問（FAQ）

**Q. 「認識されないアプリ」と表示されて起動できない**
現在の署名はテスト証明書（自己署名）のため、Windowsが発行元を認識できません。「詳細情報」→「実行」で起動できます。正式リリースでは信頼された証明書での署名に切り替える予定です。

**Q. インストールに時間がかかるのはなぜ？**
Ollama本体（1.5GB）とAIモデル（3.4GB）など、**合計約6GB**をダウンロードするためです。回線速度によりますが30〜90分かかります。完了まではウィンドウを閉じないでください。

**Q. インターネットなしでも使えますか？**
はい。インストール完了後は、Web検索ボタンをOFFにしていれば完全にオフラインで動作します。機密資料の質問にも安心して使えます。

**Q. アップロードした文書はどこに保存されますか？**
パソコンの中（`C:\Program Files\ShineosQA\data`）だけです。外部に送信されることはありません。※ 再インストールすると初期化されます。

**Q. 会社で使ってもいいですか？**
はい。モデル・ソフトウェアは商用利用可能なライセンス（Apache 2.0 等）です。導入支援やカスタマイズのご相談は https://shineos.com/contact/ まで。

**Q. バージョンアップはありますか？**
GitHub Releases ページで新しいバージョンを公開した際は、インストーラを再実行してください（データは初期化されます）。
